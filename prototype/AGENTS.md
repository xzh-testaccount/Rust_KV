# 前端协作约定

## 页面与组件

- 新增或修改页面、组件前，先参考 `components/design_lab`，并优先复用其中已有的组件、布局模式和样式。
- 设计变更必须同步维护前端设计文档与组件库，确保实现、文档和 `components/design_lab` 保持一致。
- 必须使用既有设计 token；禁止绕过 token 硬编码样式，或通过复制粘贴制造重复组件。
- 界面文案与交互提示保持中文优先；本项目是无后端原型，仅实现前端展示、交互和本地状态。

## 运行与验证

- 仅在本地启动和访问，不创建、保存或部署 Sites 项目。
- 每次改动后，在 `prototype` 目录执行 `npm run lint` 与 `npm run build`；涉及交互的改动还应在本地启动后检查关键页面流程，并确认无控制台错误。
- 提交前检查改动范围，确保未引入重复组件、未破坏既有页面，并如实记录未能完成的验证。
