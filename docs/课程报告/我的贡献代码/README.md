# 我的贡献代码

本文件夹汇总课程报告所需的前端、项目文档和 MVP 运行文件。

## 内容

- `前端/`：来自项目 `prototype/` 的前端源代码、配置文件、静态资源和前端设计文档。
- `文档/`：来自项目 `docs/` 的项目设计、接口、测试与验收文档；课程报告原文件未重复嵌套到这里。
- `mvp/`：从 Git 最早提交 `69df2c9e7ad546eb87e60bdf3aa5db293fbcead6` 提取的 MVP 完整 Rust 源码、测试和工程配置；`bin/` 中保留当前已有的可执行文件。

前端依赖目录、构建缓存和临时产物未复制，以避免文件夹过大；MVP 原目录当前仅有 `target/` 构建产物，因此源代码直接从 Git 首版记录恢复。
